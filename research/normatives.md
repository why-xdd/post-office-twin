# Нормативная база проверок планировки ОПС

Источник правил для движка валидации и для объяснений ИИ-ассистента. Каждое правило в продукте
ссылается на пункт документа — это и есть «обозначенное допущение», которого требует ТЗ
(«если вывод зависит от принятого правила комплектования или другого допущения, обозначьте его»).

## 1. ВНТП 311-98 «Объекты почтовой связи»
Ведомственные нормы технологического проектирования, утв. Приказом Госкомсвязи РФ от 30.04.1998 № 82.
Открытый текст: ruscable.ru/info/snip/Data1/49/49762/ · карточка: docs.cntd.ru/document/1200034156

| Норматив | Значение | Пункт |
|---|---|---|
| Площадь операционного рабочего места: приём/выдача **посылок** | **7,5 м²**, расстояние от стены до барьера **3,0 м** | п. 3.9 |
| Площадь операционного рабочего места: письменная корреспонденция, бандероли, подписка | **6,0 м²**, от стены до барьера **2,0 м** | п. 3.9 |
| Площадь зоны для посетителей | **15–20 м² на одно операционное место** | п. 3.9 |
| Ширина прохода между рабочими местами | не менее **1000 мм** | табл. 13, п. 4.5 |
| Рабочая зона одного работника | **800 мм** | табл. 13, п. 4.5 |
| Проход от стены до границы рабочей зоны | **800 мм** | табл. 13, п. 4.5 |
| Проход от стены до торца оборудования | **800 мм** | табл. 13, п. 4.5 |
| Кладовая обработки посылок к выдаче | **200%** среднесуточного входящего + **60%** исходящего объёма | п. 3.10 |
| Высота конвейера для укладки почты | 450–750 мм от пола | п. 4.9 |

Ключевое следствие для продукта: **норма «15–20 м² на одно операционное место» связывает число окон
с площадью клиентской зоны**. Это готовая проверка, которую больше никто не сделает.

## 2. Приказ Минцифры России от 26.10.2020 № 538
«Об утверждении нормативов размещения отделений почтовой связи…», рег. Минюст 29.10.2020 № 60659.
Открытый текст: pravo.ppt.ru/prikaz/mincifry-rossii/n-538-240669 · publication.pravo.gov.ru/document/0001202010300030

| Численность населённого пункта, тыс. чел. | Обслуживает одно ОПС, тыс. чел. | Пункт |
|---|---|---|
| свыше 500 | 15 | п. 2 |
| 250–500 | 10–15 | п. 2 |
| 100–250 | 6–10 | п. 2 |
| до 100 | до 6 | п. 2 |
| сельские поселения | 5 | п. 3 |

**п. 4:** для отделений с несколькими окнами обслуживания расчётное количество населения
**умножается на количество окон**. То есть число окон в плане напрямую определяет зону охвата —
связка «планировка ↔ норматив сети», готовый аналитический «сверх-ответ» поверх ТЗ.

## 3. СП 59.13330.2020 «Доступность зданий и сооружений для МГН»
СНиП 35-01-2001, утв. приказом Минстроя от 30.12.2020 № 904/пр (с Изменением № 3 от 19.09.2024
№ 630/пр). Полный текст выгружен в `sp59.txt`.

| Норматив | Значение | Пункт |
|---|---|---|
| Поверхность прилавков, **низа окон касс**, мест обслуживания для посетителей на кресле-коляске | не более **0,80–0,85 м** над уровнем пола | 8.1.7 |
| Проём для ног у места обслуживания | ширина и высота ≥ **0,75 м**, глубина ≥ **0,5 м** | 8.1.7 |
| Часть стойки-барьера обслуживания | высотой **0,85 м** от пола | 8.1.7 |
| Ширина рабочего фронта прилавка/стойки у места получения услуги | не менее **1,0 м** | 8.1.7 |
| Зона досягаемости для посетителя в кресле-коляске | сбоку — не выше 1,4 м и не ниже 0,3 м; фронтально — не выше 1,2 м и не ниже 0,4 м | 8.1.7 |
| Ширина путей движения в коридорах | не менее **1,8 м**; допускается **1,5–1,2 м** с карманами длиной ≥ 2 м при общей ширине ≥ 1,8 м в пределах прямой видимости; по расчёту при не более одного инвалида на этаже — ≥ **1,4 м** | 6.2.1 |
| Диаметр зоны самостоятельного разворота кресла-коляски на 180° | не менее **1,4 м** | 6.1.8 |
| Пространство для манёвра перед дверью при открывании «к себе» | не менее **1,5 × 1,5 м**; со стороны ручки ≥ 0,6 м («к себе»), ≥ 0,3 м («от себя») | 6.1.8 |
| Глубина тамбура при прямом движении | не менее **2,45 м** при ширине ≥ 1,6 м | 6.1.8 |
| Горизонтальные площадки до и после пандуса | при одностороннем движении **1,5 × 1,5 м**; при встречном — ширина 1,8 м, длина 1,5 м | 5.1.16 |
| Место для кресла-коляски | не менее **0,9 × 1,2 м** | — |
| Зона рабочего места инвалида (без поверхности стола) | **1,5 × 0,9 м** | — |

Ключевое следствие: **высота низа окна кассы 0,80–0,85 м и рабочий фронт ≥ 1,0 м** — прямая проверка
для `cashier_window` из формата заказчика, а ширина прохода 1,8 / 1,4 м — для путей клиента.

## 4. Перечень оборудования ОПС (материал заказчика)
Из `data/perechen_oborudovaniya_OPS.docx` — правила комплектования, заданные самим Почтатехом:

- терминал управления очередью (талонный автомат) — у входа, **радиус не более 3 м**;
- пандус при входе — ширина **от 1,2 м**, уклон **до 1:12**;
- рабочий стол оператора — высота **0,7–0,9 м**, выемка для ног глубиной **0,5 м**;
- центральное информационное табло — монитор **42–48"**; медиапанели — **40–46"**;
- состав зон: обслуживание клиентов · рабочее место оператора · безопасность и коммуникации ·
  вспомогательные элементы.

## 5. Формат данных заказчика
`data/example_plan.json` — координаты в метрах, начало в левом нижнем углу, `position` у оборудования
это центр объекта, `size_m` = [длина по X, длина по Y], `rotation_deg` по часовой.
Содержит `flow_hints` (маршруты клиентов с долями 55/30/15%, 220 посетителей в день, визит 7 мин,
часы пик), `operator_position` у окон, `capacity_persons` у мест ожидания,
`equipment_types_catalog` из 14 типов и явное указание на расширяемость каталога.
